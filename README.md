# Speedy Chef

لعبة مطعم عربية سريعة تعمل مباشرة من المتصفح بواجهة RTL، ولا تحتاج إلى خطوة بناء أو خادم تطبيق. افتح `index.html` محليًا أو استضف المستودع عبر GitHub Pages.

## دعم الهاتف

الواجهة الآن متجاوبة مع الهاتف أولًا. تم تحسين التمرير العمودي، أحجام أزرار اللمس، بطاقات الزبائن، محطات الطهي، نافذة اختيار الشيف، ونوافذ النجاح والخسارة. على الشاشات الأضيق من 380px تتحول بطاقات الزبائن إلى عمود واحد لتجنب التزاحم، مع إزالة اختصارات لوحة المفاتيح غير المفيدة على الهاتف. جميع مناطق اللعب الأساسية تستخدم `touch-action: manipulation` لتقليل تأخر اللمس والضغط المزدوج.

## ما تم تحسينه

تتضمن النسخة الحالية إصلاح عرض هدف المرحلة، دورة مؤقتات المطبخ، الحفاظ على المنتجات الجاهزة حتى جمعها، واستمرار وصول الزبائن بعد امتلاء الطابور. كما أصبحت إعادة المرحلة تنظف كل المؤقتات والحالات السابقة، وأصبح انتهاء صبر عدة زبائن في اللحظة نفسها آمنًا ولا يتخطى أي عنصر.

أضيف نظام شخصيات قابل للاختيار والحفظ محليًا. نور شيف متوازن، وفادي يسرّع الشواية، ولينا تسرّع القلاية والمشروبات، وعمر يمنح الزبائن صبرًا أطول ومكافأة سلسلة أكبر. توجد أيضًا اختصارات لوحة مفاتيح للشوايات والقلاية والمشروب والإيقاف.

## التشغيل المحلي

يمكن تشغيل اللعبة بأبسط خادم ملفات:

```bash
python3 -m http.server 4173
```

ثم افتح `http://127.0.0.1:4173/index.html`.

## التحقق

فحص الصياغة والمؤشرات الأساسية متاح عبر:

```bash
python3 test_speedy_chef.py
```

تستخدم اللعبة Tailwind CDN وFont Awesome وGoogle Fonts من أجل التصميم الحالي، لذلك يلزم اتصال بالإنترنت لتحميل هذه الموارد الخارجية، بينما منطق اللعبة نفسه لا يعتمد على ملفات صور أو خادم خلفي.
